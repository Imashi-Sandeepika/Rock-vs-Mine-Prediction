# 🪨💣 Rock vs Mine Prediction using Machine Learning

## 📌 Project Overview
This project applies **Logistic Regression** to classify sonar signals as either a **Rock (R)** or a **Mine (M)**.  
The model is trained on the **Sonar Dataset** from the UCI Machine Learning Repository and demonstrates the complete machine learning workflow — from data preprocessing to model evaluation and prediction.

Developed in **Python** using **Google Colab**, this project is a practical introduction to binary classification in machine learning.

---

## 🎯 Objectives
- Build a binary classification model using Logistic Regression  
- Train the model on sonar signal data  
- Predict whether an object is a Rock or a Mine  
- Understand key ML concepts: preprocessing, training, evaluation, and prediction  

---

## 📊 Dataset
- **Source:** [UCI Machine Learning Repository – Sonar Dataset](https://archive.ics.uci.edu/ml/datasets/connectionist+bench+(sonar,+mines+vs.+rocks))  
- **Instances:** 208  
- **Features:** 60 numerical attributes  
- **Target Classes:**  
  - `R` → Rock  
  - `M` → Mine  

Each feature represents the energy of a sonar signal within a specific frequency band.
